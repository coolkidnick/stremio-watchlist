Import your Stremio library

Paste a plain list of titles (one per line; years, bullets and blank lines are fine) or Stremio API JSON. Everything imported counts as seen, is never suggested, and is pulled out of To Watch automatically.

Paste box

Examples: Kes (1969), • The Long Good Friday, or JSON like {"result":[{"_id":"tt0064541","name":"Kes","type":"movie"}]}.

Sync from Stremio optional

Signs in to api.strem.io directly from this page and pulls your library. Your password is never stored. If the request is blocked, use the paste box instead.

Settings

Everything is stored in this browser. Nothing leaves it except optional calls to TMDB and Stremio.

TMDB posters & synopses

Paste a free TMDB key: a v3 API key or a v4 API Read Access Token. Posters, ratings and synopses load for visible cards and are cached. Without a key you get typographic cards.

Stremio add-on

Builds a static Stremio add-on (manifest + catalogs) from your current suggestions and To Watch list, leaving out anything seen or not interested. Unzip it into your GitHub Pages repo (it contains an addon/ folder) and push.

Backup

Export seen, To Watch, not-interested and settings (secrets excluded) as JSON. Importing a backup replaces what's here.

Reset

Wipes everything this app stored in this browser and reloads the 20 starter picks.
